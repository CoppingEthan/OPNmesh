# Router instructions for site "site-c" (Warehouse)
# Next hop for all mesh routes: the OPNmesh gateway at 10.30.10.2

## Static routes
10.10.10.0/24 via 10.30.10.2    # site-a Staff vlan 10
10.10.20.0/24 via 10.30.10.2    # site-a Voice vlan 20
10.10.30.0/24 via 10.30.10.2    # site-a CCTV vlan 30
10.10.99.0/24 via 10.30.10.2    # site-a Management vlan 99
10.20.0.0/16 via 10.30.10.2    # site-b
10.99.0.0/24 via 10.30.10.2    # mesh tunnel addresses
10.99.1.0/24 via 10.30.10.2    # roaming clients (aggregate only — never per-client routes)

## This site's networks
10.30.10.0/24  (Office, vlan 10) — carried across the mesh
10.30.40.0/24  (Scanners, vlan 40) — carried across the mesh
10.30.99.0/24  (Management, vlan 99) — carried across the mesh, restricted to admin sources by the gateway firewall
192.168.1.0/24  (Guest Wi-Fi, vlan 90) — NOT carried across the mesh (guest) — stays local to this site

## Firewall
# Block LAN hosts from opening connections to roaming clients (defense in
# depth — the gateway already enforces this with conntrack):
LAN-IN: drop NEW connections from any local network to 10.99.1.0/24
# Guest networks must not reach the mesh at all:
LAN-IN: drop connections from 192.168.1.0/24 to 10.99.0.0/24 and all remote site subnets

## WAN
Forward UDP port 51820 to 10.30.10.2 (WireGuard on this gateway).

## Note for UniFi gateways
A static route alone is NOT enough on UniFi: traffic is silently dropped
unless a matching LAN-IN firewall rule allows the routed subnets.
